  5. Penyimpanan progres dapat menggunakan localStorage tanpa memerlukan backend pada versi awal.

## Kesepakatan Tim

- Setiap anggota menggunakan akun GitHub pribadi dan tidak membagikan password.
- Fitur dikerjakan pada branch masing-masing sesuai Issue yang telah ditentukan.
- Setiap perubahan kode harus melalui proses review sebelum di-merge ke branch utama.
- Branch `main` dijaga agar tetap stabil dan dapat dijalankan.
- Setiap anggota bertanggung jawab menguji perubahan yang dikerjakan.
- Peran anggota dapat dirotasi dan setiap perubahan peran dicatat.
- Kontribusi kode, desain UI/UX, konten pembelajaran, dokumentasi, review, dan QA harus memiliki bukti yang dapat diperiksa.
- Git dapat dikerjakan melalui fitur Source Control pada IDE atau melalui terminal.
- Setiap anggota harus mengacu pada PRD.md dan AGENTS.md sebagai pedoman utama proyek.
- Perubahan terhadap fitur, alur pembelajaran, atau ruang lingkup produk harus disepakati bersama sebelum diterapkan.
- Penggunaan external skills harus mengikuti kesepakatan tim dan tidak boleh bertentangan dengan PRD maupun AGENTS.md.
- Versi dan sumber skill desain yang digunakan harus dicatat agar seluruh anggota menggunakan acuan yang konsisten.
- Setiap perubahan penting dan hasil pengujian dicatat dalam AI_LOG.md.
